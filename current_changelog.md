# Version 1.0 | Initial Release

# Library mod for Dillon's mods.
### These are planned to Include Quality of Queso, the Speedrunner Mod, Simple Keybinds, Survival Fly, and Enchantment Transferring.

## Developer Notes
- Provides all information required to create a mod on multiple modding platforms (ex. Fabric, Forge and NeoForge).
    - Only compatible with 26.2, 1.21.11, 1.21.1 and 1.20.1.
    - For 1.20.1, only Forge and Fabric are compatible.
- Provides other miscellaneous resources, like player data based on UUID, tick calculations, mixin predicates, scheduled tasks that run within the Minecraft server tick, a clean options system, common texts and client-side operations.
- DillonLib does not require any other outside resources or mods, other than Fabric API for fabric users.
